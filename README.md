# Yashwant

**Systems Software Engineer | C++ · Linux · Performance · Backend Systems · AI/LLM**

I build and debug production C/C++ systems at **IBM India Software Labs**, with experience in compiler backends, runtime behavior, and performance engineering. My work connects low-level systems with developer tooling and modern AI workflows, including an MCP service for context-aware compiler artifacts.

**M.Tech in Computer Science, IIIT Delhi.** Interested in systems, C++, performance, backend, developer tools, and AI infrastructure roles.

## What I work on

- Building and debugging C/C++ systems, from code generation and register allocation to production defect resolution.
- Investigating memory management, multithreading, runtime behavior, and performance with Linux and GDB.
- Designing developer tools with reproducible evidence, persistent state, and clear failure handling.
- Connecting engineering context to AI-assisted workflows through MCP and model APIs.
- Working with NLP, information retrieval, BM25, TF-IDF, and retrieval-augmented generation.
- Building backend APIs and applications that turn technical ideas into usable tools.
